# Tarvena dla Claude

Wersja 0.97.6. Operaty wodnoprawne, mapy, zlewnie, obliczenia i wnioski w projektach Tarvena.

```text
/plugin marketplace add niedabylskim/claude-plugins
/plugin install tarvena@tarvena
/reload-plugins
```

W `/mcp` wybierz Tarvena i **Authenticate**, zaloguj się i wybierz **Zezwól**.
[Połączenie i uprawnienia](https://tarvena.pl/docs/assistants/connect.md).

Rozpocznij od `/tarvena:operat-from-outlets` albo opisz zadanie po polsku.
Procedury znajdują się w `plugins/tarvena/skills`. Dla projektu na dysku użyj
`/tarvena:local-project` w Claude Code z zainstalowanym Tarvena CLI.

W Tarvena odłączysz dostęp przez **Ustawienia → Konto → Asystenci AI → Odłącz**.
